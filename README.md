# upsun-xhttp-relay (English)

This is an **XHTTP Relay** server designed to run on [Upsun](https://upsun.com). It proxies requests to a specified target domain.

## Configuration

The target domain is currently set to: `https://thumbayan.com:443`

## Deployment on Upsun

This project includes the necessary `.upsun/config.yaml` file for deployment.

1. Push this repository to GitHub.
2. Connect your GitHub repository to Upsun.
3. Deploy!
